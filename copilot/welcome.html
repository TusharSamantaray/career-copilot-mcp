2. Add it to your assistant

Muse Recommended: tested most
  1. Add a custom connector and paste the address.
  2. When asked, click Allow and sign in with GitHub, then approve on GitHub.
  3. Start a chat with Career Copilot turned on. Muse can also open job pages in its browser for you, which makes company research and job search work best.
Claude (web, desktop or phone)
  1. Settings → Connectors → Add custom connector.
  2. Name it Career Copilot, paste the address, leave the other fields empty.
  3. Click Connect. A Career Copilot page asks Connect Career Copilot? Click Allow and sign in with GitHub, then approve on GitHub.
  4. In a new chat, turn Career Copilot on from the tools menu.
ChatGPT
  1. Settings → Apps & Connectors → Advanced → turn on Developer mode (paid plans only).
  2. Create: name Career Copilot, paste the address, authentication OAuth.
  3. Sign in with GitHub when asked, then pick it from the + menu in a chat.
Claude Code, Cursor, VS Code and others

Add it as an HTTP MCP server with the address above. For Claude Code: claude mcp add --transport http career-copilot {{MCP_URL}}, then run /mcp to sign in.

You need a free GitHub account to sign in. Career Copilot only sees your public GitHub name and never asks for a password.
